# 轻量文件分享工具 PRD

版本：MVP v1.0

日期：2026-11-13

## 1. 产品目标

面向团队和 AI Agent 的轻量文件分享工具。成员通过网页管理本地上传或 AI 生成的文件，发布和撤销分享链接；接收者无需登录即可通过链接访问内容。网页和 CLI 使用同一套后端 API。

第一版只做文件分享，不扩展为网盘或协作文档。

## 2. 用户与场景

### 团队成员

- 上传本地文件，查看和搜索已有文件。
- 为文件创建分享链接，复制给接收者。
- 查询分享状态，随时撤销分享或删除文件。

### AI Agent

- 通过 Skill 理解操作流程，通过 CLI 上传和分享本地文件，包括 AI 生成的成果。
- 查询已有文件及其分享状态和链接。
- 按文件 ID 撤销分享。

### 接收者

- 无需登录，通过链接查看文件信息、预览或下载文件。
- 分享撤销后，链接无法继续访问。

## 3. MVP 功能范围

| 模块 | 功能 |
| --- | --- |
| 身份认证 | 团队共用一个管理账号；CLI 使用访问令牌 |
| 文件上传 | 单文件上传，默认上限 100 MB，可配置 |
| 文件列表 | 显示名称、大小、上传时间、分享状态，支持名称搜索 |
| 文件分享 | 手动开启分享，生成不可猜测的链接 |
| 撤销分享 | 立即禁用链接，文件继续保留 |
| 文件删除 | 删除文件，同时使分享链接失效 |
| 接收页面 | 展示文件名、类型、大小，提供下载；图片和 PDF 支持浏览器内预览 |
| CLI | 上传、列表、详情、开启分享、撤销分享、删除 |
| Skill | 指导 Agent 使用 CLI，将结果链接返回用户 |

不包含：成员权限体系、文件夹、批量上传、在线编辑、版本管理、分享密码、有效期、访问统计、自定义域名。

## 4. 核心规则

1. 上传成功后默认未分享；上传与分享为独立动作，CLI 可用一个命令连续完成。
2. 每个文件最多有一个有效分享链接，重复开启分享返回现有链接。
3. 撤销后重新分享生成新链接，旧链接永久失效。
4. 同名文件允许存在，以文件 ID 区分。Agent 遇到同名候选时先确认目标。
5. 撤销阻止后续访问，无法收回已经下载的内容，也不保证中止已开始的传输。
6. 文件访问必须经过后端验证分享状态，不暴露可绕过验证的存储地址。
7. 删除文件同时撤销分享。

## 5. 网页结构

### 登录页

输入管理账号和密码。

### 文件管理页

提供搜索、单文件上传、文件列表及以下操作：

- 未分享文件：开启分享、删除。
- 已分享文件：复制链接、撤销分享、删除。
- 删除已分享文件前需要确认。

### 公开分享页

展示文件信息、预览和下载入口。失效链接统一提示“分享不存在或已失效”。图片和 PDF 之外的文件只提供下载。

## 6. CLI 与 Skill

CLI 暂定名：`fileshare`。

```bash
# 配置服务地址及令牌
fileshare config set --server https://share.example.com --token <token>

# 上传并立即分享
fileshare upload ./report.pdf --share --json

# 查询文件
fileshare list --search report --json
fileshare get <file-id> --json

# 开启或撤销分享
fileshare share <file-id> --json
fileshare revoke <file-id> --json

# 删除文件
fileshare delete <file-id> --json
```

### CLI 约定

- 支持 `--json` 结构化输出，便于 Agent 解析。
- 上传并分享成功时返回 `file_id`、`name`、`share_url`、`share_status`。
- 失败返回非零退出码，错误信息写入 stderr。
- 令牌支持环境变量配置，不写进 Skill。

### Skill 工作流

| 用户指令 | Agent 行为 |
| --- | --- |
| 分享本地 report.pdf，把链接给我 | 检查路径 → 上传并分享 → 返回链接 |
| 查一下之前的报告 | 搜索文件 → 展示候选文件及分享状态 |
| 停止这个报告的分享 | 确定文件 ID → 撤销 → 返回结果 |

Skill 应包含配置前提、命令示例、JSON 输出说明、错误处理及同名文件的确认规则。

## 7. 技术方案

- 后端：Go + Gin，提供管理 API 和公开分享访问。
- 管理界面：TanStack Start + React + TypeScript，采用 SPA 模式构建静态资源，由 Go 服务托管。
- CLI：Go，调用同一套管理 API。
- 数据库：SQLite，保存文件元数据和分享状态。
- 文件存储：服务器本地目录，以 Docker Volume 持久化。
- 部署：单个 Docker 服务，后端同时托管前端静态资源。

分享链接使用安全随机令牌；管理接口要求认证；文件使用服务端生成的 ID 存储，避免文件名导致路径问题。数据库及文件目录均需持久化。

## 8. 验收标准

1. 网页上传文件后列表可见，默认无法公开访问。
2. 开启分享后，未登录接收者可通过链接预览或下载。
3. 撤销后，原链接不能再发起预览或下载。
4. 重新分享后新链接有效，旧链接仍失效。
5. CLI 可以独立完成上传、查询、分享和撤销。
6. Agent 按 Skill 能完成“分享本地 PDF 并返回链接”的完整流程。
7. 服务重启后，文件、分享状态及有效链接保持不变。
8. 未认证请求不能执行文件管理操作。
9. 删除文件后，文件不可下载，原分享链接失效。
