# MVP 实施计划

依据：docs/PRD.md、docs/DATABASE.md、docs/schema.sql、agent.md。

## 技术栈

- 后端：Go + Gin，提供管理 API 和公开分享访问。
- 前端：TanStack Start + React + TypeScript，采用 SPA 模式构建静态资源。
- CLI：Go，调用同一套管理 API。
- 数据库：SQLite，仅使用逻辑外键。
- 文件存储：服务器本地目录，通过 Docker Volume 持久化。
- 部署：单个 Docker 服务，由 Go + Gin 同时托管 API 和前端静态资源，不额外运行 Node.js 服务。

当前状态：MVP 已实现；本地服务、真实 Go CLI、Chrome 浏览器、Docker 和 Compose 验收均通过。详细证据见 docs/ACCEPTANCE.md。本计划按依赖顺序执行，每阶段完成对应验证后进入下一阶段。

## 1. 工程骨架与接口约定

- [x] 初始化 Go 模块，使用 Gin 组织 HTTP 路由和中间件，建立 cmd/server、cmd/fileshare、internal、web、skills/fileshare 目录。
- [x] 初始化 TanStack Start + React + TypeScript 前端，配置 SPA 模式、开发代理和生产静态资源构建。
- [x] 明确服务配置：监听地址、公开访问地址、数据目录、100 MB 默认上传上限、管理员账号/密码哈希、CLI 令牌哈希、会话签名密钥。
- [x] 在 docs/API.md 固定路由、认证方式、请求响应、分页方式和错误码；网页与 CLI 共用管理 API。
- [x] 文件响应统一包含 file_id、name、mime_type、size_bytes、created_at、share_status、share_url（未分享时为空）。错误响应包含 code、message。

接口范围：

| 方法 | 路由 | 用途 |
| --- | --- | --- |
| POST | /api/login | 网页登录，设置有期限的签名 Cookie |
| POST | /api/logout | 清除 Cookie |
| GET | /api/session | 查询网页登录状态 |
| POST | /api/files | multipart 单文件上传 |
| GET | /api/files | 按名称搜索、分页列表 |
| GET | /api/files/:id | 查询文件详情及分享状态 |
| POST | /api/files/:id/share | 幂等开启分享 |
| DELETE | /api/files/:id/share | 幂等撤销分享 |
| DELETE | /api/files/:id | 删除文件 |
| GET | /s/:token | 公开分享页 |
| GET | /api/public/shares/:token | 公开文件信息 |
| GET/HEAD | /api/public/shares/:token/content | 预览或下载，支持 PDF 所需的 Range |

完成标准：服务与前端可独立启动；API 文档足以指导两端实现。

## 2. 存储与业务服务

- [x] 实现 SQLite 初始化和版本化迁移，沿用 files、shares 两张表。
- [x] 严格遵循 agent.md：只使用逻辑外键，不生成物理外键或跨表触发器。
- [x] 实现本地文件存储：随机存储键、临时上传、大小限制、类型检测、失败清理。
- [x] 实现文件列表、名称字面量搜索、稳定分页、详情查询和软删除过滤。
- [x] 实现分享事务：检查文件存在且未删除，重复开启返回原链接，并发时最多一个有效分享。
- [x] 实现撤销与重新分享：旧记录永久失效，新记录使用新的安全随机令牌。
- [x] 实现删除事务：同时标记文件删除并撤销分享，提交后清理磁盘文件；失败清理可在重启时重试。

完成标准：业务集成测试覆盖重名、并发分享、重复撤销、重新分享旧链接失效、删除后禁止分享和读取；数据库无物理外键。

## 3. HTTP 服务与接收者访问

- [x] 实现网页登录、退出、Cookie 认证和 CLI Bearer Token 认证；所有管理接口统一鉴权。
- [x] Cookie 写操作加入 CSRF 防护；令牌和密码不进入日志或响应。
- [x] 实现管理 API、参数检查、错误映射、上传大小限制。
- [x] 公开接口每次联查有效分享及未删除文件，失效时统一返回不可用信息。
- [x] 服务端流式输出文件，支持 HEAD、Range、下载文件名编码，设置 no-store。
- [x] 仅允许安全的图片类型和 PDF 内联预览；HTML、SVG 等主动内容按附件下载，避免用户上传内容在应用域执行。
- [x] 托管前端资源，区分 API、公开页面及管理界面路由。

完成标准：HTTP 测试证明未认证管理访问被拒绝、有效链接可访问、撤销和删除后内容请求失败；原始存储路径不能公开访问。

## 实施边界

不增加成员权限、文件夹、批量上传、编辑、版本、密码分享、有效期、访问统计或自定义域名。暂不引入对象存储、任务队列或额外业务表。每完成一阶段更新本计划勾选状态，并记录实际验证结果；未验证的项目不标记完成。
