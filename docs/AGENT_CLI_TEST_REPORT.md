## 测试范围与方法

- 从当前源码重新编译 Go 服务和 CLI，使用真实子进程调用 CLI，检查退出码、stdout、stderr、JSON 字段及服务端状态。
- 启动独立端口的临时服务，使用随机凭证和临时 SQLite/文件目录；未使用或修改当前 8080 服务的数据。
- 核对匿名内容请求与原 PDF 的 SHA-256，检查撤销及删除后的 404，而非仅凭命令输出判断成功。
- 对分享失败、请求超时、无效 JSON 和 HTTP 重定向使用受控 HTTP 故障服务。其中“上传成功但分享失败”通过代理访问真实后端，只对首次分享注入 500。
- 独立 Agent 显式读取仓库中的 Skill，并在两轮额外的隔离服务中处理自然语言请求；CLI 工作流测试与 Agent 行为观察分别记录。

环境：macOS 26.5.2 arm64、Go 1.26.0、Python 3.14.2。上传边界测试将隔离服务上限配置为 **1 MiB**，测试恰好达到上限和超过 1 字节；不以此声称已经实传默认 100 MiB 的文件。

## 复现方法

从项目根目录执行，仅需 Go 和 Python，无需运行网页或停止现有服务：

```bash
mkdir -p work/agent-cli/bin
export GOPROXY=https://mirrors.aliyun.com/goproxy/
export GOSUMDB=sum.golang.google.cn
go build -o work/agent-cli/bin/server ./cmd/server
go build -o work/agent-cli/bin/fileshare ./cmd/fileshare
python3 scripts/test_agent_cli.py \
  --bin-dir work/agent-cli/bin \
  --output work/agent-cli/results.json
go test -count=1 -race -v ./...
go vet ./...
```

[测试脚本](../scripts/test_agent_cli.py) 会自动准备 PDF、随机凭证、独立服务和故障注入端点，完成后停止服务、清理临时文件并输出 JSON 证据。它复现 CLI 层测试；独立 Agent 行为验证需按 S01—S13 的自然语言场景单独执行，不由该脚本冒充 Agent。
